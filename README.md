# ATM System in Java

## Description

This project is a simple Automated Teller Machine (ATM) system
created using Java and Object-Oriented Programming (OOP).

## Features

- Account login
- Check balance
- Withdraw money
- Deposit money
- Food payment
- GCash payment
- Load payment
- Exit system

## Technologies Used

- Java
- Object-Oriented Programming
- Visual Studio Code

## OOP Concepts Used

- Classes
- Objects
- Inheritance
- Encapsulation
- Methods
- Constructors
